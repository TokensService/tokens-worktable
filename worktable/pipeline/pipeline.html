节点环境

名称IP 地址用户名密码设备状态操作

主控「环境（可多选）」按此列表选择目标 IP；执行脚本时自动注入环境变量：TARGET_IP（首个节点 IP）、TARGET_IPS（全部 IP 的 JSON 数组）、TARGET_HOSTS（全部节点 [{ip,user,pass}] 的 JSON 数组，多节点各自凭据）、TARGET_USER/TARGET_PASSWORD（首个节点凭据）、IMAGE_NAME/IMAGE_TAG、PIPELINE_NAME；脚本显式配置的同名参数优先。

代码仓

名称URL用户名访问令牌分支获取部署策略操作

主控「代码仓」从此列表选择目标仓库；执行脚本时自动注入环境变量：GIT_URL（仓库地址）、GIT_BRANCH（主控填写的分支）、GIT_USER/GIT_PASSWORD（访问令牌）；脚本显式配置的同名参数优先。分支获取选 Jenkins（浏览器直连/服务端代连）时仓库 URL 可留空，分支取自 Jenkins 多分支任务子任务名。配置「部署策略 URL」后，主控选择分支即可下拉选择该分支支持的部署策略，运行时额外注入 DEPLOY_STRATEGY（脚本显式配置的同名参数优先）。

环境清理脚本

脚本 勾选主控「先清理环境」后，每次流水线启动前会先执行该脚本（失败不阻断启动），同样注入 TARGET_*/IMAGE_*/PIPELINE_NAME 与归档相关 ARCHIVE_DIR/ARCHIVE_FOLDER/ARCHIVE_PIPELINE/ARCHIVE_TAG 环境变量。

归档配置

每个任务的回显即时归档为独立日志文件 run-<tag>-NN-任务名.log（NN 为 01 起的阶段序号，00 为环境清理），运行结束再写汇总 run-<tag>.log 与 profiling JSON；均按「流水线名称_日期」文件夹归档到此目录；留空则保底写到 scripts 同级 runs/（不执行归档脚本）。
归档写入日志/profiling 后执行该脚本收集日志；默认 scripts/collect_logs.sh（脚本不存在则跳过）。同样注入 TARGET_*/IMAGE_*/PIPELINE_NAME 与 ARCHIVE_DIR/ARCHIVE_FOLDER/ARCHIVE_LOG_FILE，失败不影响运行。运行启动时即按「流水线名_日期」生成归档文件夹，并把 ARCHIVE_DIR/ARCHIVE_FOLDER/ARCHIVE_PIPELINE/ARCHIVE_TAG 注入到流水线每个任务（脚本阶段、Jenkins 阶段、清理脚本），脚本显式参数优先。

分析配置 运行历史标题行分析按钮的提示词模板

在「运行历史」点击选中某一行后，点标题行的 🔍 AI 日志分析 / 📈 Profiling 分析 / ⚡ 性能诊断 按钮会新建一个 AI 会话并发送对应提示词。 模板占位符：{no} {pipeline} {env} {by} {commit} {status} {dur} {time} {tag} {summary}（单行运行摘要）{archive}（归档文件夹）{logFile} {profileFile}（归档内日志 / profiling 文件，未配置归档时为「（未归档）」）。

页面修改配置 右上角「页面修改」按钮发送给 AI 的提示词模板

点右上角「页面修改」按钮会新建一个 AI 会话并发送此提示词，由 AI 协助修改本页面。留空保存将恢复为默认提示词。

Jenkins 服务配置 连接模式 + 测试连接

「本地浏览器连接」：浏览器直接用 JS 连接 Jenkins（不走桥接）；需 Jenkins 允许跨域（CORS）或与本页同源，否则浏览器会拦截跨域请求。 「远程服务器端连接」：由 DSH 服务端（运行 DSH 的机器）经 /api/worktable/proxy 代连 Jenkins，浏览器不直连；仅允许回环 / 内网地址。
