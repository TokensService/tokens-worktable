如何看懂曲线形状

形状含义典型成因
近乎水平、噪声小健康稳态分配/释放平衡，无泄漏
单调线性上升疑似显存泄漏张量未释放 / KV block 未回收 / 权重重复加载
阶梯式增长对象逐步累积per-request tensor 存进未清理的列表 / 缓存无上限
锯齿状、基线缓升碎片化 / 缓存波动分配器碎片化、临时缓存周期涨落但未真正释放

泄漏判定决策流

显存是否持续上涨？→ 否 → 健康 / 碎片→ 查 empty_cache 后是否回落
是 → 空载无请求是否仍涨？→ 是 → 常驻泄漏（权重/池/闭包）
否 → 仅在有请求时涨 → 请求级泄漏（KV/张量/上下文）
空载仍涨指向常驻对象；仅请求时涨指向 per-request 资源未回收。先用此分流再选定位工具。
