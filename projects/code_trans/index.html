使用说明

  • 令牌仅在本机服务端调用平台 API 时使用，不经过浏览器直连，避免 CORS 与泄露。
  • 同步机制：克隆目标仓 → 抓取源 PR 提交 → cherry-pick 到 sync/<平台>-<编号> 分支 → push → 调用 API 建 PR/MR。
  • 冲突会自动中止该 PR 并继续其余；查看日志了解失败原因。
  • 「状态」与「合入分支」chips 叠加过滤源仓 PR 列表：状态按 开放 / 已合并 / 全部 单选，合入分支按目标分支多选，各 chip 带分类计数；「全选」仅选中当前筛选结果。
  • 设置页「抓取状态」控制向平台请求的 PR 范围（默认 all = 全部状态）；页面 chips 仅在已抓取范围内做显示筛选，切换即时生效。
  • 「试运行」会执行 cherry-pick 自检但不会 push 也不会建 PR，适合先验证。
  • 「执行位置」可选本地或已配置的远程服务器：选远程时，本机 SSH 到该服务器、把脚本与 spec 传过去后执行 pr-sync.py，输出实时回流；服务器需有 python3 与 git。认证支持密码 / 密钥；主机指纹 TOFU（首次接受并记住，变更可「重置主机指纹」）。PR 抓取（列表 / 测试连接）始终在本地。
