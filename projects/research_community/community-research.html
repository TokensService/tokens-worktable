推理大模型社区分析

添加社区链接 → 勾选目标 → 写提示词 → 选 AI Code Agent 分析；支持持续对话式追问（Kimi Code / MiMo Code / Codex / Claude Code）

社区链接

勾选要分析的社区链接（可多选），首轮分析会把所选链接连同下方提示词交给所选 AI Code Agent；链接保存在浏览器本地。

AI Code Agent 对话式分析

待命 CLI Agent 在服务端非交互运行，续聊沿用同一会话上下文
· 社区链接保存在浏览器本地（localStorage），可随时添加 / 删除，支持勾选多个目标组合分析；「恢复默认」回到内置的四个推理框架社区链接。
· CLI Agent（Kimi Code / MiMo Code / Codex / Claude Code）在服务端以非交互模式运行（kimi -p / mimo run / codex exec / claude -p），输出实时回显；续聊沿用同一服务端会话（kimi -c / mimo run -c / codex exec resume --last / claude -p -c），运行目录为本页目录下的 .ai-community/。需执行环境已安装对应 CLI。
· Agent 可自行抓取链接内容（curl / gh api / 网页）做深入分析；分析结果由所选模型生成，仅供参考。
